# SportsBuilder logo concepts

Six editable SVG directions preserve the LearnUnlock teal and ink palette. These are proposals; none replaces the application logo yet.

Open `brand-board.svg` to compare full lockups, small-size reductions, monochrome, and reversed uses. Each named SVG contains only its mark; `*-wordmark.svg` adds the SportsBuilder name. SVGs use ordinary editable geometry without external images, scripts, or stylesheets. Wordmark and board text request Lexend with a local sans-serif fallback; mark-only files have no font dependency.

| Direction | Design idea |
| --- | --- |
| Trajectory S | One continuous measured path |
| Articulated SB | Shared spine and two measured arcs |
| Grounded Stride | Movement with a stable ground reference |
| Joint Frame | Recording bounds meet articulated geometry |
| Folded S | Bold solid mark for compact use |
| Progression | Successive positions become a forward rhythm |

Test the marks at 16, 24, and 32 pixels and as one-color shapes before choosing. Stroke-based marks can be outlined in a vector editor for final distribution. No trademark clearance is implied by this design exploration.
