# SportsBuilder identity studies

Six logo candidates and two original eight-icon families for comparison. These
remain a comparison archive. Progression is the user-approved app mark and favicon;
the icon families remain proposals.

- [Figma study](https://www.figma.com/design/llHeNiPGkHeeEtKAqAwibW/SportsBuilder-Logo-Icon-Studies)
- [Interactive comparison](index.html): serve the repository root, then open
  `/docs/design/`. The local review server uses `http://127.0.0.1:5180/docs/design/`.
- [Logo board](brand-concepts/brand-board.svg) and [icon board](icon-concepts/icon-board.svg)
- [Combined Figma import](figma-concept-board.svg): editable vector geometry,
  with Lexend labels outlined so Figma does not depend on imported font resolution.
  Original specimen boards retain text nodes.

The comparison swaps the sidebar mark and icon family, checks actual 16/24/32px
sizes, switches the mark to monochrome, and links individual SVG downloads.
Keep navigation labels when testing unfamiliar custom icons.

`prepare-figma.py` regenerates the combined import from the two original boards
and the bundled Lexend font. Its invocation is documented in the script.
