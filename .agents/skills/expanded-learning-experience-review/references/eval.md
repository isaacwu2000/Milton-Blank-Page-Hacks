# Learning experience evaluation

Apply the complete evaluation in this order:

1. [Block failures](eval/block-failures.md)
2. [Non-pedagogy quality](eval/non-pedagogy-quality.md)
3. [Pedagogy quality](eval/pedagogy-quality.md)
4. [Scoring](eval/scoring.md)

Evaluate every applicable binary and Likert criterion. For an artifact, also select the
applicable branch in [artifact-family notes](notes/artifact-families.md), treat every
applicable family bullet as a binary criterion, and assign the artifact-family Likert
score defined in pedagogy quality.

Continue through the complete evaluation after a block failure. Mark required untested
criteria `Unknown`, exclude only genuine `N/A` criteria, and calculate the final score
using the scoring rules. Do not infer a verdict from a numeric threshold.
